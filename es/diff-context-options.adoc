`-U<n>`::
`--unified=<n>`::
	Genera diferencias con _<n>_ líneas de contexto. El número de líneas de contexto es predeterminado a `diff.context` o 3 si se omite la configuración de la variable. (`-U` sin `<n>` se acepta silenciosamente como sinónimo de `-p` por un accidente histórico).

`--inter-hunk-context=<n>`::
	Muestra el contexto entre pedazos de diferencia, hasta el _<número>_ especificado de líneas, a modo de fusionar pedazos cercanos. Predeterminado a `diff.interHunkContext`o 0 si no se configura la opción.
